# Central de Atendimento

Projeto desenvolvido para a atividade de Desenvolvimento Web I.

A ideia do projeto é criar uma página de uma central de atendimento
para facilitar a solicitação e o acompanhamento de chamados de suporte
técnico.

## Funcionalidades

- Página inicial com apresentação da central;
- Exibição dos principais serviços de suporte;
- Página com chamados cadastrados;
- Formulário para abertura de novos chamados;
- Campos para nome, e-mail e telefone;
- Seleção de categoria e prioridade;
- Data e hora da ocorrência;
- Campo para descrição do problema;
- Campo para informar equipamentos ou serviços afetados;
- Possibilidade de anexar um arquivo;
- Confirmação das informações antes do envio;
- Layout adaptado para diferentes tamanhos de tela.

## Tecnologias utilizadas

- HTML5;
- CSS3;
- EditorConfig;
- Prettier;
- Visual Studio Code;
- Git e GitHub.
